## Compatibility notice

Cepheus Trader v0.7.10 retains **CT-RPC 7**, administrator and sysop protocol
2, and storage manifest 1. The Flight Plan proposal and snapshot record codecs
advance to 2, and the outcome codec advances to 14. The v0.7.10 server accepts
v0.7.9 Flight Plan messages and planner records through explicit legacy
handling, so no universe-wide store migration is required.

Compatibility is server-forward, not fully symmetric. A v0.7.9 door can use a
v0.7.10 server, but a v0.7.10 door sends the new separate terminal marker that
a v0.7.9 server does not interpret. Upgrade the server first, or upgrade the
server, door executable, and `cepheus-trader-client-core` library together.

## Highlights

- Separated Flight Plan checkpoint authority from plan completion. Hold waits
  for arrival watch, Through can continue under standing orders, and a distinct
  marker ends the plan after its final step.
- Added independent task-route and ordinary-route defaults, automatic Through
  operation while the captain is away, and numbered step-specific warnings for
  docking deadlines and manual arrival-watch requirements.
- Published a comprehensive player-facing Game Rules reference covering the
  underlying world, task, trade, finance, ship-operation, travel, encounter,
  combat, career, prize, warrant, and weapon concepts used by the game.
- Expanded the illustrated Ship Catalog with 98 new canonical vessel plates
  and improved filtering, sorting, wraparound navigation, and asset caching.
- Hardened Windows player-identity registry replacement so updates preserve the
  registry owner's protected access controls.
