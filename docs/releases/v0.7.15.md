# Cepheus Trader v0.7.15

Cepheus Trader v0.7.15 advances the player protocol from **CT-RPC 10 to 11**
and replaces the anonymous speculative exchange with the sourced merchant
procedure.

## Player-visible changes

- Commodity values are references, not free executable quotes.
- Supplier and buyer searches take game time and create finite counterparties.
- Price negotiation is separate timed work; quotes must be accepted or
  rejected explicitly.
- Purchases add the automatic ten-percent loader charge.
- Buyer markups use actual purchase or appraisal basis, and purchased cargo
  cannot be resold at its acquisition port.
- Import tariff belongs to the buyer; the merchant's export tariff is charged
  when the ship clears its origin berth.
- Prohibited physical contacts use Streetwise; prohibited online buyer work
  uses Computers; price negotiation still uses Broker.

## Compatibility and migration

CT-RPC 10 doors cannot connect to a v0.7.15 server. Upgrade the server and
player door together. On first open, the server refunds legacy market-lead
escrow and clears obsolete searches, leads, observations, market events, and
daily exchange state. Existing cargo is retained and treated as tariff-paid;
new cargo records acquisition and valuation provenance.

Retained outcomes use codec 30, ship records codec 6, merchant work codec 2,
market leads codec 2, and queued commands codec 4. The storage manifest remains
format 2.
